# Smart EMI Planner - Store Assets

This folder contains marketing assets, screenshots, and promo tiles for the Chrome Web Store and Microsoft Edge Add-ons Store listings.

## Recommended Specifications

| Asset | Dimensions | Format | Usage |
| :--- | :--- | :--- | :--- |
| **Store Icon** | 128 x 128 px | PNG | Upload to "Store Listing > App Icon" (uses `/public/favicon.png`) |
| **Screenshots** | 1280 x 800 px (or 640 x 400 px) | PNG / JPEG | Upload 1 to 5 screenshots to "Store Listing > Screenshots" |
| **Small Promo Tile** | 440 x 280 px | PNG / JPEG | Upload to "Store Listing > Promotional Tiles" |
| **Marquee Tile** | 1400 x 560 px | PNG / JPEG | Optional marquee banner featured on store homepages |

> Note: Google and Microsoft require you to upload these images directly on the web store dashboard form. They are not bundled into the user's extension `.zip` to keep the extension download fast and lightweight (< 1MB).
